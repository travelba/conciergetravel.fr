## Garde-fous (à respecter à l'envoi)

- **Aucun e-mail inventé** : la colonne `contact` du CSV cibles est vide quand
  l'adresse n'est pas publique — la sourcer manuellement avant envoi.
- **Un chiffre, une demande, un lien** par message.
- **Pas de superlatifs bannis** (`incroyable`, `magnifique`, `exceptionnel`
  hors classification Atout France, `magique`, `sublime`).
- **Rafraîchir les chiffres** depuis `press-data-pack-2026-07.md` si le
  catalogue a bougé.
- **Respect RGPD / CAN-SPAM** : opt-out clair, base de prospection B2B
  légitime, pas d'achat de listes.
